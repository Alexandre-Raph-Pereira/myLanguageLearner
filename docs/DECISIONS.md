- 2026-11-21 — plan 00 — AI SDK v7: structured calls use `generateText({ output: Output.object({ schema }) })` and `instructions` (not `system`); schema failures surface as `NoObjectGeneratedError`, which triggers the single retry (validation error appended as a user turn after the bad assistant answer).
- 2026-11-21 — plan 00 — Mock fixtures format: `tests/fixtures/ai/<task>.json` = `{ "responses": [...], "usage"?: { input, output, cacheRead } }`; string entries are raw text (to test invalid JSON), other values are JSON-stringified; served in order per task, last repeats. Tests can override with `setMockFixture()`. Mock calls are logged with provider `mock:<provider>` and priced like the real model.
- 2026-11-21 — plan 00 — Per-request cap compares `operation.spentActual + estimate` (actual cost of earlier calls in the operation + upper bound of the next). Every attempt (incl. the retry) is budget-checked and logged; invalid-output attempts are logged as `error` with their real usage. Blocked calls are logged with status `blocked` and cost 0. Cache writes are billed at the input rate (slight underestimate, no column for them).
- 2026-11-21 — plan 00 — `aiObject`/`aiText` accept an optional `db` (tests inject PGlite); provider error messages are stored without the raw error object to avoid logging request details.
- 2026-11-21 — plan 00 — Authenticated pages live in the `app/(app)` route group (shell layout calls `requireUser()` and is `force-dynamic` so nothing per-user is prerendered at build). `/words` and `/grammar` are placeholders until plans 01/02 so the nav has no dead links.
