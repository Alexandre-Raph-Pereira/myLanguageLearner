# Decisions log (append-only)

Format: `YYYY-MM-DD — plan NN — decision — reason`

- 2026-11-21 — all — Stack: Next.js + Supabase (Postgres + Auth) + Drizzle + Vercel AI SDK — owner approved in planning.
- 2026-11-21 — all — Default model `claude-sonnet-5-5` for both tiers, configurable — owner asked for Sonnet 5.
- 2026-11-21 — plan 00 — Next.js 16.4 scaffolded with `cacheComponents` and `partialPrefetching` **disabled** — every page is per-user, request-time data behind auth; Cache Components would force Suspense around every session read for no benefit in a single-user app. Can be revisited later.
- 2026-11-21 — plan 00 — shadcn/ui (radix base, "nova" preset): `form` no longer exists in the registry, the `field` component is used instead (forms are plain server actions + zod) — closest current equivalent.
- 2026-11-21 — plan 00 — `@playwright/test` pinned to 1.63.0 to match the Chromium preinstalled in cloud sessions; `PW_CHROMIUM_PATH` env can point to another browser binary.
- 2026-11-21 — plan 00 — `pnpm typecheck` runs `next typegen` before `tsc` so the generated route types (`LayoutProps`, `PageProps`) exist on a fresh checkout.
- 2026-11-21 — plan 00 — Work happens on the session branch `claude/charming-gauss-y43prx` (the cloud session may only push there) instead of `plan/00-fondation`.
- 2026-11-21 — plan 00 — `model_pricing` is a global table (no `user_id`): prices are facts about a model, not user data. It is the only table exempt from the "scoped by userId" rule. The default-model row is seeded by migration `0001_seed_pricing` (placeholder $3 / $15 / $0.30 per MTok, `verified=false`) so production has a row too; Settings shows a "verify prices" banner.
- 2026-11-21 — plan 00 — Numeric money columns use Drizzle `mode: "number"` (JS numbers) — amounts are small, float precision is fine for budgets.
- 2026-11-21 — plan 00 — Domain functions take a `Db` argument (driver-agnostic type in `db/types.ts`) so the same code runs on postgres-js and PGlite in tests; `db/index.ts` exports a lazily connected `db`.
- 2026-11-21 — plan 00 — Next.js 16 renamed `middleware.ts` to **`proxy.ts`**; the plan's middleware lives there. Unauthenticated `/api/*` requests get a JSON 401 instead of a redirect.
- 2026-11-21 — plan 00 — `requireUser()` redirects to `/login`; `requireUser({ throwOnMissing: true })` throws `UnauthorizedError` (status 401) for route handlers/server actions. Bootstrap rows are upserted once per server process per user.
- 2026-11-21 — plan 00 — The login action answers "link sent" for non-allowed emails too (no allow-list leak) and never sends them a link; the callback still signs out non-allowed users as a second check.
- 2026-11-21 — plan 00 — Dev-only `DATABASE_URL=pglite://<dir>` runs the app on an embedded PGlite database (rejected in production). Together with `DEV_USER_ID` this lets e2e tests and cloud sessions run without Supabase. `pnpm db:migrate` is a small tsx script (drizzle migrator) that supports both URL kinds. `getDb()` is async (driver loaded lazily) instead of a top-level `db` export.
- 2026-11-21 — plan 00 — AI SDK v7: structured calls use `generateText({ output: Output.object({ schema }) })` and `instructions` (not `system`); schema failures surface as `NoObjectGeneratedError`, which triggers the single retry (validation error appended as a user turn after the bad assistant answer).
- 2026-11-21 — plan 00 — Mock fixtures format: `tests/fixtures/ai/<task>.json` = `{ "responses": [...], "usage"?: { input, output, cacheRead } }`; string entries are raw text (to test invalid JSON), other values are JSON-stringified; served in order per task, last repeats. Tests can override with `setMockFixture()`. Mock calls are logged with provider `mock:<provider>` and priced like the real model.
- 2026-11-21 — plan 00 — Per-request cap compares `operation.spentActual + estimate` (actual cost of earlier calls in the operation + upper bound of the next). Every attempt (incl. the retry) is budget-checked and logged; invalid-output attempts are logged as `error` with their real usage. Blocked calls are logged with status `blocked` and cost 0. Cache writes are billed at the input rate (slight underestimate, no column for them).
- 2026-11-21 — plan 00 — `aiObject`/`aiText` accept an optional `db` (tests inject PGlite); provider error messages are stored without the raw error object to avoid logging request details.
- 2026-11-21 — plan 00 — Authenticated pages live in the `app/(app)` route group (shell layout calls `requireUser()` and is `force-dynamic` so nothing per-user is prerendered at build). `/words` and `/grammar` are placeholders until plans 01/02 so the nav has no dead links.
- 2026-11-21 — plan 00 — Settings uses native `<select>` for level/provider (best UX on phones, trivial in e2e); each section is its own server-action form validated by zod schemas in `lib/settings.ts`. Pricing is edited for the resolved smart/fast model ids; saving a row sets `verified=true` and the "Verify prices" banner disappears once all configured models are verified.
- 2026-11-21 — plan 00 — e2e (Playwright) runs `next dev` with `DEV_USER_ID` + `DATABASE_URL=pglite://./.pglite-e2e` (recreated by `e2e/prepare-db.ts`) and `AI_MOCK=1`, on a Pixel 7 viewport.
- 2026-11-21 — plan 00 — Placeholder PWA icons ("한" in a ring) are rendered from SVG by `pnpm icons` (scripts/generate-icons.mjs, uses Playwright's Chromium — no image library dependency). The manifest is served at `/manifest.webmanifest` and is excluded from the auth proxy together with `/icons/*` and `/apple-touch-icon.png`. No service worker (online only).
- 2026-11-21 — plan 00 — CI has two jobs: `check` (lint, typecheck, test with `AI_MOCK=1`, build with dummy env) and `e2e` (Playwright, installs its own Chromium). `db:migrate`/`db:seed` load `.env.local` via `node --env-file-if-exists`.
- 2026-11-22 — plan 00 — `DATABASE_URL` is normalized before reaching postgres.js (`db/url.ts`): unknown query params such as `supa=base-pooler.x` / `pgbouncer=true` (present in Vercel–Supabase integration URLs) are dropped, because postgres.js sends them to the server as startup parameters and the pooler rejects the connection. Remote hosts default to `ssl: require`. `pnpm db:migrate` prints the redacted URL and the underlying error cause.
- 2026-11-22 — plan 00 — Placeholder price seeded by migration 0001 ($3/$15/$0.30) is above Sonnet 5.5 list price ($2/$10/$0.10 per MTok). The applied migration is not edited; the dev seed uses the new values and the owner corrects/verifies the row in Settings.
