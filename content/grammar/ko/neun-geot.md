## Description

`-는 것` turns a **verb into a noun**, like "-ing" or "to …" in English: 먹다 → 먹**는 것** = eating. The result is used like any noun: subject, object, topic.

1. **As a noun**: 한국어를 배우**는 것**은 재미있어요 = learning Korean is fun.
2. **Contracted in speech**: `것` + particle is shortened, and the contraction tells you its role in the sentence:
   - `것이` → **게** (subject): 운동하**는 게** 좋아요 = exercising is good / I like exercising.
   - `것을` → **걸** (object): 운동하**는 걸** 좋아해요 = I like exercising.
   - `것은` → **건** (topic): 운동하**는 건** 중요해요 = exercising is important.

Remember: **게 = subject, 걸 = object, 건 = topic**.

## Formation

- Verb stem + `는 것`, same after a vowel or a consonant: 가다 → 가**는 것**, 먹다 → 먹**는 것**, 운동하다 → 운동하**는 것**.
- ㄹ-stems drop the ㄹ: 만들다 → 만드**는 것**, 살다 → 사**는 것**.
- `있다 / 없다` (and 맛있다, 재미있다) also take `는`: 재미있**는 것**.
- Spoken contractions: `것이 → 게`, `것을 → 걸`, `것은 → 건`. Formal writing keeps the full forms.
- `-는 것` is the present / general form. Past and future use the other modifiers: `-(으)ㄴ 것` (먹은 것 = what I ate), `-(으)ㄹ 것` (먹을 것 = something to eat). Adjectives take `-(으)ㄴ 것` (예쁜 것).

## Examples

| Use     | Korean                                   | English                                 |
| ------- | ---------------------------------------- | --------------------------------------- |
| Noun    | 한국어를 배우**는 것**은 재미있어요.     | Learning Korean is fun.                 |
| Noun    | 제 취미는 책을 읽**는 것**이에요.        | My hobby is reading books.              |
| Object  | 운동하**는 것**을 좋아해요.              | I like exercising.                      |
| Subject | 운동하**는 게** 좋아요.                  | Exercising is good. / I like exercising. |
| Subject | 혼자 사**는 게** 쉽지 않아요.            | Living alone isn't easy.                |
| Object  | 운동하**는 걸** 좋아해요.                | I like exercising.                      |
| Object  | 요리하**는 걸** 싫어해요.                | I don't like cooking.                   |
| Topic   | 운동하**는 건** 중요해요.                | Exercising is important.                |

## Similar · be careful

- **좋아하다 vs 좋다**: 좋아하다 (to like) takes an **object** → `-는 걸 좋아해요`. 좋다 (to be good / pleasing) has a **subject** → `-는 게 좋아요`. Same for 싫어하다 (걸) vs 싫다 (게).
- **vs `-기`**: also makes a noun from a verb, but is used in fixed patterns (`-기 쉽다 / 어렵다`, `-기 시작하다`, `-기 좋아하다` in writing). `-는 것` is the general, everyday nominalizer.
- **Tense**: ~~먹었는 것~~ is wrong; use 먹**은 것** for the past.
- **`-는 것 같다` is a different grammar**: "it seems that…" (비가 오**는 것 같아요**).
