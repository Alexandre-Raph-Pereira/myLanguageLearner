# Rewriting a grammar lesson draft

Guidance only: return exactly the fields requested by the app.

## Follow the instruction literally
- Do what the learner asked, and only that. "Shorter description" changes the
  description, not the examples. "More examples" adds examples and keeps the others.
- If the instruction is in the learner's native language or mixes languages, still
  follow it; write the result in the languages the app asks for.
- If the instruction cannot be done (asks for something unrelated to the lesson), make
  the smallest sensible change and keep the rest.

## Keep what is right
- The learner may have edited the draft by hand: their edits are intentional. Keep every
  field, sentence and example that is correct, in the same order and wording.
- Keep correct examples even if you would have written them differently.
- Fix a real mistake (wrong conjugation, spacing, mistranslation) only when no
  instruction is given, or when it is inside the part you are asked to change.

## Without an instruction
- Fix mistakes and complete missing parts (formation, at least three examples, similar /
  be careful), keeping the learner's content first.

## Style
- Same tone and length as the existing draft unless asked otherwise. Concise.
