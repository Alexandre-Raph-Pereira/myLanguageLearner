# langlearner-agents

The tutor's brain: working directory of the local Claude Code process that answers the
app's AI requests when `AI_PROVIDER=claude-code` (plan 07). It holds **how the tutor
teaches** (role, learner profile, one skill per AI task, personas, evals). Editing these
Markdown files changes the teaching style without touching app code.

Full guide: written in plan 08 T9.
