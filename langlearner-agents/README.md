# langlearner-agents

Working directory of the local Claude Code process that answers the app's AI requests
when `AI_PROVIDER=claude-code` (plan 07). The app reads `CLAUDE.md` and puts it at the
top of every request's system prompt; Claude Code runs here with no tools.

Plan 08 (`docs/plans/08-langlearner-agents.md`) fills this folder with the learner profile,
one skill per AI task, personas and evals.
